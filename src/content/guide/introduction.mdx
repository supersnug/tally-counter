# Count simply. Build further when you need to.

Tally is a local-first counting workspace. You can create a counter and start counting without registering or configuring anything.

An optional account adds cloud synchronization, counter-copy sharing, and live group counters. Scripting and Tally Super stay out of the way until you choose to use them.

<Important>Accounts are optional. Personal counters continue to be stored in your browser even when you sign out or delete an account.</Important>

## Choose where counters live

| Counter type | Storage | Best for |
| --- | --- | --- |
| Personal | Browser and optional cloud sync | Everyday counters |
| Local counter | This browser only | Device-specific data |
| Shared group counter | Group storage only | Live collaboration |
