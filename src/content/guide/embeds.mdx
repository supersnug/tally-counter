# Place a focused counter on another website

The embed builder creates an iframe snippet and a live preview. Open it from the code icon on a personal counter.

## How embeds differ

An embed carries its counter configuration in the embed URL. It does not read the main Tally page's local storage or join cloud synchronization and shared groups.

## Common uses

Embed a public progress tally, event count, score, capacity display, or lightweight interactive counter in a page that supports iframes.
