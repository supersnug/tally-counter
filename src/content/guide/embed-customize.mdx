# Choose what an embed displays

Every option updates the live preview and generated iframe syntax immediately.

## Size

Choose standard sizing for a full counter or smaller sizing when space is limited. Check the preview at the width available on the destination site.

## Theme

Use Light, Dark, or device-matched appearance. Device matching follows the visitor's preferred color scheme rather than your own current Tally theme.

## Controls

Show or hide Reset and settings information according to how much interaction visitors should have. A display-only use may need fewer controls than a counter intended for participation.

## Watermark

Choose whether the “Powered by Tally” watermark appears. Removing it changes only the presentation, not the embedded counter's behavior.

<Tip>Use the smallest set of controls that still explains the counter's purpose to someone seeing it outside Tally.</Tip>
