# Recover recently deleted counters

Trash is enabled by default. Deleting a personal counter moves it into Trash for five days rather than removing it immediately.

## Time remaining

Trash displays the remaining retention time using the most useful units: days and hours, then hours and minutes, then minutes, and finally seconds.

## Work with a deleted counter

While retained, a trashed counter can still be edited or embedded. Use Restore to return it to My Counters.

## Permanent deletion

The trash icon inside Trash opens a confirmation before permanently removing the counter. When Trash is disabled, deleting an active counter uses the same permanent-deletion confirmation.

## Cloud preference

Signed-in users can choose whether deleted counters remain in cloud synchronization during their retention period.

<Critical>Permanent deletion cannot be undone through Trash. Export a backup first if the counter or its linked script may be needed later.</Critical>
