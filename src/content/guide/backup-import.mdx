# Restore or transfer a backup

Choose the Import button matching the type of file you exported. Tally validates the JSON and asks for counter-specific options when that scope supports them.

## Counter options

If a counter backup contains scripts or per-counter layouts, you can choose whether to import them. The options appear only when the file includes that information.

## Cross-device transfer

Export on the original device, move the JSON file securely, and import it on the destination. An account is not required for this process.

## Before importing

Review the backup scope and create a current All backup when the destination contains data you may need later.

<Warning>Import is a data-changing operation. Do not import an unfamiliar or untrusted backup, especially when it contains scripts.</Warning>
