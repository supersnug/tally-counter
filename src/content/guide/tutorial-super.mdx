# Rearrange Tally with Tally Super

The embedded Tally Super settings are the production controls. **Start editor** opens the real toolbox pane with a temporary counter and temporary customization data.

<LiveSuperLesson />

## Build a workspace

Toggle zone snapping or editor labels, then start the editor. Toolbox items expand for their real preview and presets; dragging uses the same placement and transform behavior as the workspace.

## Customize a counter

The counter editor uses the counter's real dimensions. It can reposition the title, value, controls, goal bar, and indicators, or expose checked quick settings directly on the counter.

Required elements cannot be deleted, fixed-size action icons cannot be resized, and default elements can appear only once. A removed optional default can be added again from the toolbox.

<Tip>Use the editor preview as the source of truth: placed counters use their real count, limits, and final-goal progress.</Tip>
