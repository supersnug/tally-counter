# Send a copy or count together

A **counter copy** gives the recipient an independent counter. A **group counter** remains shared and updates for every member.

<Important>Choose a copy when each person should own a separate result. Choose a group when everyone should continue changing the same live counter.</Important>

## Counter copies

Send by username or email and optionally include the script and Tally Super customization linked to that counter. Recipients choose which additions to accept and whether the copy should remain local.

## Groups

Group owners create shared counters and invite members. Shared counter data, scripts, and customizations live only in the group and are never inserted into personal counter data.

Permission presets include Full Access, Settings Only, Scripts Only, Super Only, and Counting Only. Custom access controls individual actions, settings, languages, and Super elements.

<Tip>Begin with the closest preset, then use Custom only when a member needs a specific combination of abilities.</Tip>
