# Store and move customization safely

Tally Super is kept separate from core counter values so a visual customization cannot corrupt counting data.

## What gets saved

Workspace layouts and per-counter layouts are saved separately. This lets you reset or transfer one kind of customization without replacing the other.

<Important>A Tally Super-only backup does not include individual counter layouts. Use All, or include per-counter customizations with a Counters backup, when you need those layouts too.</Important>

For signed-in users, Tally Super changes synchronize with the rest of their account preferences. A shared counter keeps only its own layout, not customizations from your personal counters.

## Backup choices

The Backup menu provides Counters, Tally Super, and All operations:

- **Counters** can optionally include linked per-counter customizations and scripts.
- **Tally Super** exports the workspace layout and general customization preferences, but not individual counter layouts.
- **All** includes counters, scripts, global customization, and every per-counter customization.

The counter-specific inclusion choice appears in a secondary modal so a quick export does not permanently change backup behavior.

## Counter-copy sharing

When sending a counter copy, you may include only the Tally Super customization linked to that counter. The recipient sees that option only if customization was supplied and may decline it while still accepting the counter.

## Group permissions

Group permissions separate each editable Super element. Editing the delete button's layout is distinct from permission to delete the shared counter itself. Indicator permissions and quick-setting permissions are also separate—for example, the minimum indicator is not the minimum setting.

## Removing old customization

Use Remove in the relevant Super editor to delete a placed customization. Importing a clean Super backup or resetting an element can also restore defaults without changing counter values.
