# Control deletion and cloud storage

Trash protects recently deleted counters. Local Counter controls whether an active personal counter participates in cloud synchronization.

## Separate purposes

Trash is about recovery after deletion. Local Counter is about data location while a counter exists. A counter can retain its local status even when the option is temporarily unavailable.

- [Recover or permanently delete counters →](/guide/trash-local/trash)
- [Keep a counter only on one device →](/guide/trash-local/local)

<Tip>Use Local Counter for device-specific data. Use Trash when you simply need a chance to undo deletion.</Tip>
