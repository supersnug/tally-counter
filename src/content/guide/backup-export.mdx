# Export the right backup

Choose Export under Counters, Tally Super, or All. Tally downloads a JSON file that can be stored like any other document.

## Counter export options

After choosing Counters, a second modal asks whether to include per-counter customizations and scripts. These options include only data linked to the exported counters.

## Tally Super exports

A Tally Super export is intended for the workspace and general appearance. It does not contain individual counter layouts because those layouts have no meaning without their counters.

## Complete exports

All includes every supported backup area and always includes scripts and per-counter customizations.

<Tip>Create an All backup before large imports, account deletion, or extensive Tally Super editing.</Tip>

## Store files safely

Backup files may contain counter names, values, scripts, and custom layouts. Treat them as personal data and avoid publishing them accidentally.
