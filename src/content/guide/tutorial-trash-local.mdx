# Control recovery and data location

This playground reproduces the counter, Local counter switch, Trash toolbar, restore action, countdown, and permanent-deletion confirmation. All changes stay inside the lesson.

<LiveTrashLesson />

## Practice the Trash workflow

1. Turn on **Local counter** and notice its yellow banner.
2. Use the counter's delete button to move it into the simulated Trash.
3. Click the counter's trash button again to open the permanent-deletion modal, or use Restore in the Trash toolbar.

Counters remain in Trash for five days before automatic deletion.

## Try a local counter

For a signed-in user, enabling **Local counter** removes its cloud copy while keeping the device copy. The yellow banner appears only when the option is available to change. It is intentionally hidden in this Trash simulation, matching Tally when deleted counters are not being stored in the cloud.

<Warning>A local counter exists only in that browser unless you transfer it with a backup.</Warning>
