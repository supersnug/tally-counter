# Choose a comfortable counter layout

Appearance settings change presentation without altering counter values or rules.

## Theme

Switch between light and dark modes from the top bar. The selected theme persists across the landing page, counters workspace, and guide.

## Card spacing

Choose Compact, Comfortable, or Spacious. Each step changes card dimensions and spacing, not merely text size.

## Number size

Choose Small, Standard, or Large values. The size differences are balanced so each option is visibly distinct.

## Columns and details

Choose how many counter columns appear when space allows and whether minimum and maximum bounds are shown on cards.

## Trash preferences

Customization settings also control whether Trash is enabled and whether trashed counters stay in cloud synchronization while signed in.

<Tip>Use Compact with more columns for dashboards. Use Spacious with larger numbers when reading counters from farther away.</Tip>
