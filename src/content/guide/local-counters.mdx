# Keep a counter on one device

Enable Local Counter in an existing counter's settings while signed in. The counter remains in this browser and is excluded from personal cloud synchronization.

## Converting an existing counter

Turning Local Counter on removes that counter from your account's cloud data. It does not remotely erase a stale copy already stored in another device's browser.

## When the option appears

The setting and yellow Local Counter banner appear only while signed in and when cloud storage is a meaningful choice. They are hidden while signed out and when a trashed counter is already excluded by the deleted-counter cloud preference.

## Status persists

The underlying local status remains saved even when the switch or banner is hidden. Signing out does not silently convert a local counter into a cloud counter.

<Important>A local counter does not transfer through account sync. Use a JSON backup when you intentionally want to move it to another device.</Important>
