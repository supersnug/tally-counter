# Keep portable copies of your Tally data

JSON backups support recovery and cross-device transfers without requiring an account. Open App Settings, choose Backup, then select the scope you need.

## Three scopes

- **Counters** contains personal counter data and can optionally include linked scripts and per-counter customizations.
- **Tally Super** contains workspace and general customization, excluding individual counter layouts.
- **All** contains counters, scripts, preferences, workspace customization, and per-counter customization.

## Choosing a scope

Use Counters for a lightweight tally transfer, Tally Super for a workspace design, and All for a complete snapshot.

<Important>Scripts are linked to counters, so they are included through the Counters script toggle or automatically through All—not as a separate backup type.</Important>
