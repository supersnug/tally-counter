# Control values and step amounts

Every counter has a current value, a starting value, and separate steps for its positive and negative buttons.

## Positive and negative values

Counters can move above or below zero. The + button always adds; the − button always subtracts. Neither the current value nor your goals need to be positive.

## Independent steps

Positive and negative steps do not need to match. A stock counter might add deliveries in boxes of `12` but subtract individual sales by `1`.

<Tip>Step amounts are always treated as positive sizes. Choose the button to determine whether that amount is added or subtracted.</Tip>

## Exact value

Use Exact value when you know the correct current count and want to replace it directly. This does not change the starting value used by Reset.

## Jump to a saved value

Jump provides shortcuts to the counter's starting value, goals, minimum, and maximum. It is useful when those values would be slower or error-prone to enter manually.
