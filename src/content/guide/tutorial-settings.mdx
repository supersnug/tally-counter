# Make the workspace yours

This embedded Customize panel uses the same choices and switches as App Settings. Its changes apply only to the demonstration counter beside it.

<LiveSettingsLesson />

## Try an appearance setup

Switch between Compact, Comfortable, and Spacious, then try Grid columns, Number size, Counter details, and Animations. The preview responds without changing saved preferences.

Other customization controls use the same idea: theme changes the whole interface, number size changes counter values, and column settings change how the counter grid uses available width.

## Review and reset stats

The Stats menu reports Session Actions, Net Movement, Total Distance, Most Active, Active Counters, and Goals Complete. In the app, selecting an individual statistic resets it; **Reset all stats** clears every statistic.

<Tip>Appearance changes affect the workspace, not the numerical behavior of a counter.</Tip>
