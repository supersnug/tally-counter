# Add the iframe to a website

Copy the generated iframe syntax from the embed builder and paste it into a location that accepts custom HTML or iframe embeds.

## Test the route

The iframe source uses Tally's `/embed` route. Open the preview before publishing and test the deployed page after pasting the snippet.

## Website restrictions

Some hosted site builders block arbitrary iframes or require an Embed/Custom HTML block. Follow that platform's instructions if pasted HTML appears as text.

## Responsive layouts

Place the iframe inside a container that fits its configured size. If the destination page is narrow, choose the smaller embed option rather than shrinking it with browser zoom.

<Warning>Do not manually edit the encoded counter data in the URL. Return to the builder, change the options, and copy the newly generated snippet.</Warning>
